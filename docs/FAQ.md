# WDM2VST Ultra 常见问题 FAQ

## 录音相关

### 录出来的声音有很微小的噪声是怎么回事？

如果你没打开 DAW，只用录音软件录 Ultra REC 通道，波形上能看到非常微弱的底噪，这是 Windows 系统的正常行为，不是插件或驱动的问题。

**原因**：Windows 在"共享模式"下（MME、DirectSound、默认的 WASAPI）会对音频做格式转换、采样率转换、多应用混音，每一步都会加入非常轻微的处理噪声（约 -96 分贝，基本听不到）。所有虚拟声卡都有这个现象，甚至硬件声卡在共享模式下也一样。

**解决办法**（如果你介意）：
- 在录音软件里选择 **WASAPI 独占模式** 录音
- 或者在 DAW 里用 **ASIO 驱动** 录音
- 或者把录音格式设为 **32-bit float**

独占模式下，噪声会完全消失。

---

### Studio One 里加了 W2V 插件，为什么录音没有波形？

这是 Studio One 的设定，不是插件问题。

如果 Audio 轨的 **Input 留空**，Studio One 会认为这条轨没有输入源，不会调用 W2V 插件，所以录不到任何东西。即使换成其他插件（官方的正弦波生成器也一样）都是这种行为。

**正确做法**：
1. 新建 Audio 轨
2. **Input 选 Ultra REC 1/2**（随便选一个，当作占位）
3. 在这条轨的 **Insert** 插槽里加 W2V 插件
4. 启用录音 → 正常录制

---

### 为什么 INST WDM2VST Ultra 在 Studio One 里不能录音？

Studio One 的 **Instrument 轨只能录 MIDI**，不能录音频。INST 版本被识别为乐器插件，所以 Studio One 不让它的音频被录下来（录音和监听按钮会是灰色）。

**解决办法**：在 Studio One 里用普通的 W2V（不带 INST），按上一条的方法操作。

INST 版本主要是给 Cubase、Logic 这类允许乐器轨录音频的 DAW 用的。

---

### 为什么 V2W Ultra 的延迟比 W2V 高？

这是**刻意的安全设计**，不是 bug。

**场景不同**：

- **W2V** 把外部系统音（浏览器、游戏、会议软件、播放器等）接到 DAW，**你能监听得到**，偶尔一次咔哒可以撤销或重录。
- **V2W** 把 DAW 的音频送到虚拟录音端（直播 OBS、会议、屏幕录制、语音通话等），**你听不到自己发出去的声音**。一次咔哒就会被直播观众或通话对方直接听到，甚至被永久录下。

**所以**：

- V2W 用固定 25 ms 的缓冲深度，追求**零事故**而不是最低延迟
- W2V 提供 4 种延迟档位（Safe / Fast / Extreme / Insane），由用户自己在低延迟和稳定性之间权衡
- 25 ms 的音频延迟对直播和会议**完全不可感知**（人类对话的反应延迟本身就有 100 ms 以上）

如果你确实需要 DAW 到录播软件的超低延迟路径，正确的做法不是降 V2W 延迟，而是用 DAW 原生的 ASIO 直通，绕开虚拟声卡这一跳。

## LUNA 相关

### LUNA 里 W2V 的四个延迟模式听起来一样，没有区别？

**这是 LUNA 自己的限制，不是 W2V 的 bug。**

LUNA 内部对所有插件强制使用固定的 512 采样处理块，**不跟随你在 UA Connect 里设置的 ASIO 缓冲大小**。这个是 Universal Audio 的设计，官方论坛上也有反复确认。

在这个固定大小下，我们的插件为了保证不出咔哒声，会自动把延迟提升到安全值，所以你切四个模式听起来延迟差不多。

**建议**：
- 在 LUNA 里用 W2V：**保持 Safe 模式**即可
- 如果你需要真正的低延迟差异，用 **Studio One / Cubase / Reaper** 这些 DAW，设置 128 或 256 的 ASIO 缓冲，四个模式会有明显区别

---

### LUNA 里把延迟调到 Fast / Extreme / Insane 会有咔哒声？

同样是 LUNA 固定处理块大小导致的。我们的插件已经做了兼容处理：在 LUNA 下无论你选哪个模式，实际都会用 Safe 模式的参数运行，保证不出咔哒。

---

### LUNA 里的插件图标是空白的方框？

第一次在 LUNA 里加载新插件时会是这样。LUNA 需要你**手动触发**一次图标生成：

1. 在 LUNA 中加载任意一个 WDM2VST Ultra 系列插件
2. 打开它的窗口
3. **点击窗口顶部显示插件名的那条"名字栏"**
4. 选择菜单中的 **"Create Plug-In Icon"**（创建插件图标）

之后 LUNA 会自动显示图标。

> 我们的安装包会附带 5 张专门设计的品牌图标（WDM2VST Ultra、INST、VST2WDM Ultra、Send Ultra、Receive Ultra）。安装时会自动部署到 LUNA 的图标目录，打开 LUNA 就能直接看到品牌图标，不需要手动"Create Plug-In Icon"。

---

### LUNA 里 W2V 有时要开关一下插件才有声音？

这是 LUNA 加载工程时的偶发现象。目前临时的解决方法是**在插件下拉菜单里重新选一次通道**（比如切到 None 再切回来，或者切到同一个通道）。

如果你能稳定复现这个现象，欢迎把操作步骤发给我们，我们会针对性修复。

---

### LUNA 里能录 W2V 的输出吗？

目前 LUNA 对第三方 VST3 插件的输出录制有自己的逻辑，我们还在研究兼容方案。

**临时方案**：把 LUNA 作为**播放端**使用（W2V 接收其他应用的音频），录音请用 Studio One / Reaper 等其他 DAW。

## 其他

### 为什么 Windows「设置 → 系统 → 声音」里的 Ultra 端点顺序是乱的？

打开 Windows 11 的「设置 → 声音」，把输入/输出设备列表展开，你可能看到 Ultra 端点的顺序是乱的（比如 27/28、29/30、15/16、31/32 混在一起），既不按通道号也不按名字。

**这是 Windows 11 这个设置页的固有行为，不是驱动的问题。**

**原因**：Windows 11「设置 → 声音」这个新版列表按系统内部的端点记录顺序（端点 GUID / 首次登记次序）显示，**不参考端点的友好名做排序**，应用层无法控制。微软官方答疑也确认：这个列表的顺序无法稳定指定，手动禁用 / 重新启用只能临时改变，重启后又会回到系统的内部顺序。

参考（微软官方）：
- [How to reorder audio output list in Windows 11 — Microsoft Q&A](https://learn.microsoft.com/en-us/answers/questions/4107308/how-to-reorder-audio-output-list-in-windows-11)
- [IMMDeviceEnumerator::EnumAudioEndpoints — 枚举不保证顺序](https://learn.microsoft.com/en-us/windows/win32/api/mmdeviceapi/nf-mmdeviceapi-immdeviceenumerator-enumaudioendpoints)

**实际不受影响的地方**：

- **插件内的通道下拉框**：始终按通道号 01/02 → 31/32 升序排列，**永远是整齐的**。选通道请以插件内的列表为准。
- **经典声音控制面板**（运行 `mmsys.cpl`）和**大多数 DAW 的设备下拉框**：按友好名排序，我们已把通道号做成两位零填充（`01/02` … `31/32`），所以这些地方也是整齐的。

换句话说，只有 Windows 11 新版「设置 → 声音」那个展开列表会乱，而你平时真正用来选通道的插件下拉框和 DAW 设备列表都是有序的。

### 玩游戏时反作弊提示要卸载本驱动怎么办？

部分国内游戏的反作弊系统（如腾讯 ACE、网易易盾、米哈游 mhyprot 等）会扫描所有内核驱动，对**非 Microsoft 签名**的第三方驱动一律标记为"可疑"，无论驱动实际是否影响游戏。

我们的驱动使用合法的第三方代码签名证书（用于 Windows 内核加载），但还没有获得 Microsoft 的二次签名（attestation），所以会被这类反作弊系统拦截。这跟驱动是否真的有作弊行为无关，纯粹看签名来源。

**临时方案**：闲鱼等平台上有第三方"驱动隐藏"工具（原本面向规避反作弊驱动检测的场景），可以让反作弊系统不再提示卸载本驱动，从而正常进游戏。这类工具并非我们提供、也未经我们测试，可能存在兼容性或账号风险，是否使用请自行判断、自担风险。

**关于根治**：彻底解决要靠拿到 Microsoft 签名认证（attestation），需要正规 EV 代码签名证书（约 ¥2000-3000/年）。我们正在通过捐赠筹集这笔费用，认证落地后未来版本将不再触发此类反作弊提示：https://www.geekaudio.cn/donate/

### 驱动/插件版本号看起来不对？

- **Windows 文件属性里的版本号**：1.0.9.0 ✓
- **DAW 里显示的版本号**：1.0.9 ✓
- **LUNA 显示的版本号**：1.0.9 ✓（老版本曾经显示 0.0.0，v1.0.2 起已修复）
- **Windows 设备管理器里驱动属性**：显示当前安装的驱动版本

如果发现版本号不一致，请：
1. 在 Windows "添加或删除程序" 里**完整卸载**旧版本
2. 重启电脑
3. 重新安装最新版

1. 先看一下是不是共享模式 / Studio One / LUNA 的系统限制（看本 FAQ 有没有类似条目）
2. 尝试**完整卸载后重装**（Windows "添加或删除程序" → WDM2VST Ultra → 卸载 → 重启 → 安装最新版）
